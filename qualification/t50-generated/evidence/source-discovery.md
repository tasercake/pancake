# Bounded real-source discovery

The 2026-11-17 search examined primary dataset/repository pages for roughly
five minutes. No source qualified for all of: 50 distinct consecutive optical
focus positions, native at least 6000×4000 pixels, high-bit inputs, usable rights,
and the remaining 1,490,980,001-byte unique-download allowance. This is a bounded
search result, not a claim that no suitable source exists.

| Primary source | Observed limitation for T50 |
| --- | --- |
| [Existing focus-stack-sample](https://huggingface.co/datasets/jjjsood/focus-stack-sample) | CC BY 4.0 real Canon CR3 focus capture supports R50, but the already qualified native visible dimensions are 5118×3412. Published developed TIFFs do not establish true high-bit 24 MP T50. No upscaling or promotion was used. |
| [ZEDD](https://huggingface.co/datasets/venkatsubra/ZEDD) | Describes 100 scenes and 9 focus distances × 6 apertures. Fifty-four files per scene are not 50 distinct consecutive focus positions. JPEG image structure does not qualify the requested high-bit input. |
| [FocusStackingDataset / LSFD](https://github.com/araujoalexandre/FocusStackingDataset) | Repository describes 94 high-resolution RAW bursts. This is the existing disabled D01 source. It was not reenabled, downloaded, or substituted into an approved corpus. |

The subsequent user instruction explicitly allows generation. T50 therefore
uses the retained, open deterministic generator. It remains labeled GENERATED;
real R50, D150 and E9 source contracts are unchanged. No images were downloaded
during this discovery task, and no personal-photo search was performed.
