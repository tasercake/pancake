## Preserve state and leave the current pose unresolved

A trusted frame index, its normalized thumbnail and its anchor-to-frame map can stay in memory after a contradictory transition. These remain facts about the trusted frame. Copying its map to the current frame asserts an unmeasured stationary step. Advancing the previous proxy while retaining the old map assigns the map and proxy to different frames. Both actions can hide genuine motion.

Let `T_k` map the selected anchor coordinate to trusted frame `k`, and let `B_(j←k)` map frame `k` to frame `j`. A verified connecting edge gives `T_j = B_(j←k) ∘ T_k`. This is the existing `relative.compose(accumulated)` order for a verified adjacent match. An independently verified anchor-to-`j` fit can also reconnect a later frame. It establishes only that frame's pose. If a verified edge from unresolved `i` to the reconnected `j` is available, it can resolve `T_i = inverse(B_(j←i)) ∘ T_j` before `i` enters fusion. Motion between two unanchored frames establishes relative geometry only. Diagnostics must retain the indices of verified edges. The public sequential transform for adjacent frames remains `T_i ∘ inverse(T_(i−1))` once both endpoint poses are known.

The current `Alignment` appends a concrete `SourceMap` for every original, normalizes that image and immediately submits its pixels to the slab accumulator. Slab overlap reuses the indexed map. The final crop uses all common-canvas maps, and successful publication reports one original-raster map per source. An unresolved map therefore cannot flow through the current success path. Leaving the source out or fusing it without a measured placement changes the requested stack and its crop. The existing `Estimate::UNCERTAIN` returns identity with zero confidence for several cases, including a featureless image and near-perfect identity correlation. That history requires a separate distinction between insufficient evidence and affirmative contradiction.

An observer-only diagnostic could retain the trusted state and report the unknown relation while separately tracing the unchanged legacy result. Production would need either measured reconnection before normalization or an explicitly reviewed failure policy. The latter could use the shared recoverable job path before export or retained-result publication and cannot qualify D150 as complete. Bounded lookahead could attempt a measured link. Its pending RGB ownership, or the extra decode of a geometry pass, must enter admission and full-job cost. Current evidence justifies neither a global fallback map nor a new default failure.

## Test-first design

Freeze generated scenes and ground truth before inspecting an implementation's choices. Feed normal input files to `job::run` and the release CLI, with centered canvas geometry and independently rendered transforms. State-transition tests can exercise exact edge arithmetic and update order separately. Actual CPU and physical NVIDIA job tests must drive the same host state and CubeCL sampler. Case identities, filenames, motion sizes and D150 frames belong only to the tests.

- Render a continuous two-axis texture through focus-dependent blur and exposure gain. Estimate successive signed translations and isotropic scales within the allowed geometry. Choose noncommuting steps whose wrong composition changes a checked point by more than the existing one-pixel corner/center tolerance. Include a supported large step and a false proposal of comparable displacement. Verify the genuine map, actual warp and crop. Verify that support, rather than movement size, distinguishes the false proposal.
- Render an interior horizontal aperture whose intensity is invariant under horizontal translation. Two incompatible horizontal motions can yield the exact same samples. Repeat with periodic material and with usable texture only in one column. These tests require abstention rather than a fabricated identity, reuse of the last map, or an unsupported inverse-reverse map. Preserve the separate public flat/identity fallback behavior and the last trustworthy state.
- Disrupt a connection between two independently supported parts of the sequence. A later high-quality relative step within the unanchored part must not certify its absolute placement. A separately measured direct link reconnects the correct frame. Resolving the earlier frame requires its own verified edge to a trusted endpoint. Check First anchor now, and any later Middle or Previous extension against its existing selected anchor and adjacent-map contract.
- Exercise the same index again through slab overlap. The chosen map and normalized pixels must remain identical, and state must not advance twice. Test bounded-memory admission and controls at register/fuse boundaries. A separately approved failure policy needs an actual CLI and native GUI witness for unchanged existing output and prior retained result, no successful completion, no leaked stage, and a successful following job. A completed multi-frame request must retain the whole frame set.
