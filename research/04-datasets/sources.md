## Retrieval audit

GitHub and Drive connectors were used for supported reads. HF/Figshare public metadata retrieval used system `curl` after web fetch failure and a Python CA-store failure; no TLS verification was disabled. Drive responses retain `source_visibility_status: access_not_verified`; successful metadata/folder reads do not prove complete binary-download access. No sign-in gate, email form, contact-sharing agreement, archive publication, or author contact was performed.
