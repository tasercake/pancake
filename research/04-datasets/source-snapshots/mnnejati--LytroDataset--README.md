The **Lytro Multi-focus Dataset** provides a curated collection of multi-focus image pairs and series designed for research in image fusion, depth estimation, and computational photography.

## 📁 Dataset Overview

- **Image Pairs**: 20 pairs of color multi-focus images  
- **Resolution**: 520 × 520 pixels  
- **Series**: 4 multi-focus image series, each containing **3 source images** (different focus settings)  

This dataset is ideal for evaluating multi-focus image fusion algorithms.
