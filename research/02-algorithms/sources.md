## Search and retrieval audit

Discovery used web queries for classical wavelets, selective/noise-robust fusion, guided filtering, boundary defocus, whole-stack fusion, transformers, self-supervision, diffusion, and high-resolution work, including explicit 2024–2026 searches. AlphaXiv discovery supplied candidates only; `fullText:true` was used for the five newer arXiv papers listed above, avoiding reliance on its generated intermediate summaries.

Recent leads included other general-fusion models, but task-specific primary evidence and input contracts were prioritized over a long list of names. A search hit with a 2027 issue date was not included without verified availability by the cutoff. Negative search results cannot prove no better algorithm exists.

Full publisher access was limited for several Elsevier articles and AAAI content. Indexed original abstracts/excerpts and exact author code were used within stated limits. License availability is recorded per artifact, not inferred from public GitHub access. No dataset files, checkpoints, source example photographs, or paper PDFs were downloaded as a corpus.
